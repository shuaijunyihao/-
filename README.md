大肥鱼 QQ 机器人 · 第一次使用（教程）
==============================

你手里这个是「桥接主程序 + DSH 面板插件」的完整包。
程序作业原理

    QQ  <->  SnowLuma  <->  qq-bridge（本包）  <->  DSH  <->  模型

    1) DSH（DeepSeek-Harness）      已经在跑，能打开网页界面
    2) SnowLuma（QQ 网关）          已经在跑，已登录你的 QQ 号
    3) Node.js 22.13 或更高          没装的话先装：https://nodejs.org

完整图文步骤在 docs\FIRST_RUN.md，这里只给最短路径。


------------------------------------------------------------
安装
------------------------------------------------------------

第 1 步  解压
    解压到一个「没有中文、没有空格」的路径，例如：
        D:\qq-bridge
    不要放在 C:\Program Files 或桌面（中文用户名会出问题）。

第 2 步  装依赖
    在这个目录里打开 PowerShell 或 cmd，执行：
        npm install
    大约 30MB，要联网。装完会自动跑一个补丁脚本，别中断它。
    （包里已经带了 .npmrc，不用管 peer 依赖报警。）

第 3 步  写配置
        copy config.example.json config.json
    然后用记事本打开 config.json，只改这四处：

        "ownerQQ":           你自己的 QQ 号（数字，不带引号也行）
        "dsh": { "baseUrl":  DSH 的网址，例如 "http://127.0.0.1:3080" }
        "snowluma": { "accessToken":  SnowLuma 里的访问令牌 }
        "consoleToken":      自己随便设一个长字符串（面板密码）

    注意：SnowLuma 的 WebSocket 令牌和 HTTP 令牌是两个不同的值，
    填错了会「连上但收不到消息」。

第 4 步  装进 DSH（最容易漏的一步！）
        node scripts\setup-dsh.mjs desktop

    最后的 desktop 是 DSH 的 profile 名。不知道填什么，就去看
    这个文件夹下有哪些子目录：
        C:\Users\你的用户名\.dsh\profiles\
    常见的是 desktop 或 web，把看到的名字填进去。

    这一步会做三件事：装 QQ 对话预设、挂三个 MCP 工具、
    装右下角那个 🐟 面板按钮。

    装完必须重启 DSH，否则面板不会出现。
    不想要 🐟 按钮可以这样跑（先设环境变量）：
        set QQ_BRIDGE_SKIP_PANEL=1

第 5 步  启动
    双击 start.bat

    窗口里会滚动日志，看到连上 SnowLuma 就成了。
    这个窗口别关，关了机器人就下线。
    想后台静默运行：双击 start-hidden.vbs

第 6 步  打开面板，加白名单
    两种打开方式，任选：
        a) DSH 网页右下角那个 🐟 按钮
        b) 浏览器打开 http://127.0.0.1:3200/

    进去先看最上面那条横幅：
        绿色 = 一切正常
        黄色 = 有问题但能跑，点「一键修复」
        红色 = 跑不起来，点「一键修复」，还不行就看下面的日志

    然后在「白名单与目标」里加你自己：
        填你的 QQ 号，点「加入」
        或者填 group:群号，把整个群加进来

    加完点「让她主动开口」—— 如果 QQ 上收到消息，
    说明整条链路全通了，可以开始聊了。


------------------------------------------------------------
解决部分问题的办法
------------------------------------------------------------

她不理你
    1. 面板四个灯是不是全绿
    2. 白名单里有没有你
    3. 模式是不是 reserved2（二代仿真，推荐）
    4. 看「日志」那一页的 bridge 日志

连上了但收不到消息
    config.json 里 SnowLuma 的 accessToken 填错了，
    或者填成了 WebSocket 那个。去 SnowLuma 后台重新复制一次。

面板 404 / 打不开
    setup-dsh.mjs 装完之后 DSH 没重启。重启 DSH。

语音、唱歌没反应
    Python 环境没配好。注意：不要用 Microsoft Store 版 Python，
    它会静默失败（退出码 49）。装 python.org 的正式版。
    语音功能是可选的，不配也能正常聊天。

还是不行
    在这个目录里执行，把输出发给我：
        node scripts\doctor.mjs
    它会做 14 项检查，直接告诉你是哪一环断了。


------------------------------------------------------------
目录里的文件
------------------------------------------------------------

    start.bat            启动脚本（双击这个）
    start-hidden.vbs     静默启动（没有黑窗口）
    config.json          你的配置（自己创建，不要外传）
    config.example.json  配置模板
    src\                 桥接主程序
    admin\               后台面板（ui.html + server.py）
    plugins\dsh-bigfish\ DSH 里的 🐟 按钮插件
    scripts\             工具脚本（doctor 体检、setup-dsh 安装等）
    roles\               人格卡，想换性格改这里
    voice-tools\         语音 / 唱歌（可选，需要额外装模型）
    docs\FIRST_RUN.md    完整教程
    audio\  state\       运行时产生的东西，可以删
